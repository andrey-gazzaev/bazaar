# Базар

Маркетплейс с тремя ролями: админ, продавец и клиент.

## Запуск

Нужны Docker, Node.js 22 и pnpm.

```bash
docker compose up -d --wait
cp .env.example apps/api/.env
pnpm install
pnpm db:migrate
pnpm db:seed
pnpm dev
```

Витрина: http://localhost:3000  
API: http://localhost:3001

## Демо-аккаунты

| Email | Пароль | Роль |
| --- | --- | --- |
| admin@bazaar.dev | bazaar-admin | Админ |
| seller@bazaar.dev | bazaar-seller | Продавец |
| client@bazaar.dev | bazaar-client | Клиент |

Регистрация создаёт клиента или продавца. Админа создаёт только другой админ.

## Что умеет

- Каталог и страница товара: название, описание, цена, теги, картинки, продавец.
- Продавец добавляет и удаляет свои товары.
- Покупка одного товара: перед подтверждением адрес доставки и итог, равный цене. Заказ сохраняется как оплаченный, деньги не списываются.
- Админ правит пользователей и теги: создание, изменение, удаление.

## Тесты

```bash
pnpm test
```

Интеграционные тесты API поднимают Postgres из Docker. Модульные и интеграционные тесты витрины идут на Testing Library.
